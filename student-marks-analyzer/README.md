# Student Marks Analyzer

## Overview
A Python project that analyzes synthetic marks for 50 students across five subjects using NumPy.

## Features
- Creates and inspects a 50 × 5 NumPy array
- Demonstrates indexing, negative indexing, and 2D slicing
- Uses boolean masks to identify failing and high-scoring marks
- Classifies marks into six grade bands
- Calculates subject-wise averages, highest marks, and toppers
- Calculates student rankings and pass percentages
- Visualizes subject averages and grade distributions using Matplotlib
- Includes automated tests and grade-boundary validation

## Technologies
- Python
- NumPy
- Matplotlib
- Google Colab

## Dataset
The project uses reproducible, randomly generated synthetic marks. It contains no real student records.

## How to Run
1. Open `Student_marks_analyzer.ipynb` in Google Colab.
2. Run the cells in order.
3. Review the report, charts, and automated test results.

## Validation
The notebook checks array dimensions, score ranges, grade classifications, and statistical calculations.
